# แบบฝึกหัดทายชื่อชิ้นส่วน Factory I/O

รายวิชา 30127-2013 การใช้โปรแกรมจำลองระบบการผลิตอัตโนมัติ

หน้าเว็บแบบฝึกหัดสำหรับโทรศัพท์มือถือ มีชิ้นส่วน 65 ชิ้น แบ่งเป็น 9 หมวด ผู้เรียนดูภาพแล้วพิมพ์ชื่อภาษาอังกฤษและคำแปลไทย

ระบบตรวจคำตอบในเครื่องของผู้เรียน จากนั้นออกรหัสผล 15 ตัวอักษรให้ส่งครู และผู้เรียนบันทึกสรุปคำตอบเป็น PDF ได้

ทั้งหมดอยู่ในไฟล์เดียวคือ `index.html` ไม่มีเซิร์ฟเวอร์และไม่มีฐานข้อมูล

## เปิดใช้ด้วย GitHub Pages
1. สร้าง repository แบบ **Public**
2. อัปโหลด `index.html` ไว้ที่ราก (root) ของ repository
3. ไปที่ **Settings → Pages → Build and deployment**
4. ที่ Source เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที เว็บจะเปิดได้ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

## อัปเดต
อัปโหลด `index.html` ฉบับใหม่ทับไฟล์เดิม แล้วกด Commit เว็บจะอัปเดตเองภายในไม่กี่นาที

## ข้อควรรู้
- **สมุดคะแนนครู** ไม่ได้อยู่ใน repository นี้ ใช้สมุดคะแนนส่วนตัวใน Claude ถอดรหัสผลเหมือนเดิม เพราะรหัสผลใช้รูปแบบเดียวกัน
- **เฉลย** ถูกเข้ารหัสไว้ในหน้า อ่านจากโค้ดตรง ๆ ไม่ได้ แต่ repository แบบ Public ทุกคนเปิดดูซอร์สได้ คนที่เขียนโปรแกรมเป็นยังแกะได้
- **การบันทึก PDF** บนโทรศัพท์จะเปิดเมนูแชร์ให้เลือกบันทึกหรือส่งต่อ บนคอมพิวเตอร์จะดาวน์โหลดไฟล์
- **ภาพและชื่อชิ้นส่วน** มาจากคู่มือ Factory I/O (docs.factoryio.com/manual/parts/) ใช้เพื่อการเรียนการสอน
